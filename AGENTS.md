# Working agreement

At the start of every session inspect repository state, this file, README.md,
docs/status.md, docs/decisions.md, and the requirements-to-evidence table.

Keep the GitHub repository private unless the owner explicitly directs otherwise.
Never commit credentials, personal holdings, API response caches, or downloaded
market data. Do not add trading, prediction, or brokerage execution.

Work in bounded complete milestones. Keep mathematical derivations, code, tests,
and evidence status consistent. Separate established theory, proposed design,
implemented behavior, and measured results. Never invent source references or
claim unperformed tests, performance advantages, or successful deployments.

Preserve the independent NumPy reference when adding C++. Validate analytical
formulas, autodiff, and finite differences independently. Do not relax expectations
to make failures pass. Use meaningful invariances, edge cases, and solver residuals.

Update docs/status.md and docs/requirements.md with substantive changes. Record
reproduction commands, source/data identity and environment with measured results.
Read sources before citing them. Explain mathematics at calculus-student level.
